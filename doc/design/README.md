# Design documents

This directory holds the design documents of the library. The documents are
grouped by role and by provider. Each subdirectory has its own index.

| Subdirectory | Subject |
| --- | --- |
| [Client design](client/README.md) | The design pages of the client, which describe the `Http2.Client.*` units. |
| [Common design](common/README.md) | The design pages of the shared units in `Http2.Common`. |
| [Server design](server/README.md) | The design pages of the server, which describe the `Http2.Server.*` units. |
| [TLS providers](tls/README.md) | The design pages of the OpenSSL and TlsLib providers. |
