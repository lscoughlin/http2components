# Verification records

This directory holds the verification records of the library. Each record
states the checks of one platform, one source revision or one date, with the
results and their limits. The records are not release approvals.

| Document | Subject |
| --- | --- |
| [Current status](current-status.md) | The summary of the current results, with links to the records. |
| [Linux validation record](linux-validation-2026-11-20.md) | The full Linux x86_64 run of 2026-11-20: host, commits, stage results, peers, limits and open items. |
| [Linux performance record](linux-performance-2026-11-20.md) | The numbers of the load stages of the same run. |
| [WebSocket over HTTP/2 client record](websocket-http2-client-2026-11-20.md) | The tests, loops, volume results and open items of the WebSocket over HTTP/2 client. |
| [Client compiler probes](client-probes/README.md) | The compiler probes of the client source project, kept as historical evidence. |
