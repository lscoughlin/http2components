# Package preparation

The package inventory is generated by tools/packages.py. It assigns each
source unit to exactly one package. Common has no mORMot2 search paths.
The client and server packages depend on common. The optional Readers
package depends on client and common. Every version is 0.30.0.

The first macOS Lazarus build passed for all four packages. Its raw log is
bin/review-packages.log. The source inventory at that check was common 6,
client 19, server 73, and optional Readers 1. Client divisions will change
this inventory and require regeneration.

Lazarus rewrites the generated Pascal package sources without the required
pasdoc YAML header. The build driver restores the canonical equivalent
sources with tools/packages.py after each package build, including failure.
The --check mode detects stale inventory or source contents before a build.

Final API probes and the final source inventory remain open. No Linux or
load validation was run.
